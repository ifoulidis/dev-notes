# Isaiah's Dev Notes

A small blog built with Astro, Tailwind and Keystatic.

```sh
npm install
npm run dev     # site at http://localhost:4321, editor at http://localhost:4321/keystatic
npm run build   # type-checks, then builds to dist/
npm run preview
```

Keystatic uses local storage: posts are MDX files in `src/content/posts/` and their images live in
`src/assets/posts/`. Commit them like any other change.
